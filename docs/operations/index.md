# Operations

This book covers everything needed to deploy, run, monitor, and maintain watsonx Orchestrate in a production environment — from initial on-premises installation through to load testing and troubleshooting.

- **Platform engineers** deploying watsonx Orchestrate on OpenShift

- **Performance engineers** validating agent capacity before launch
