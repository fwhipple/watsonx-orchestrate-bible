# Channels Roadmap

Upcoming features for digital and enterprise channel integrations.

!!! warning "Roadmap accuracy"
    Items reflect information from the IBM watsonx Orchestrate Deep Dive Enablement sessions. Verify current status with your IBM account team or official release notes.

## September

| Feature | Details |
|---------|---------|
| **OAuth 2 Code for Embed Chat member credentials** | Member credential OAuth 2 Code flow support for the Embed Chat widget — allows the agent to act on behalf of the logged-in website user (mid-release) |
| **Embed Chat SSO support** | Single sign-on support for the Embed Chat channel |
| **Tool shortlisting** | Limit tool exposure per turn; improves routing accuracy across all channels |

| **Native website via Meta integration** | Native web channel support via Meta platform integration |
| **Telephony agent improvements** | Contact centre telephony agent feature improvements (details TBD per agent type) |

## November
