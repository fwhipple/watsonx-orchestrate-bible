# watsonx Orchestrate Bible

The **watsonx Orchestrate Bible** is the authoritative technical reference for IBM watsonx Orchestrate, synthesised from the IBM watsonx Orchestrate Deep Dive Enablement series. It is written for IBM field engineers and technical sellers who need precise, deep technical detail to design, implement, and troubleshoot production-grade agent deployments — not a product overview, but a complete engineering companion.

## How to use this site

| Book | Use it when… |
|------|-------------|
| **Reference** | You need to understand *what* something is, *how* it works internally, or what the configuration schema accepts. Treat it as a technical specification. |
| **Operations** | You are installing, sizing, monitoring, or diagnosing a deployment. |
| **HOWTO** | You know what you want to accomplish and need the steps to do it. Each guide is a focused, numbered procedure. |
| **Cookbook** | You need a working, end-to-end example for a specific integration pattern that you can adapt directly. |
| **Labs** | You want structured, guided practice that builds progressively from first principles through advanced topics. |

All books are independent entry points — start wherever the task at hand takes you. Reference pages are cross-linked from every HOWTO, Cookbook, and Lab page that touches the same feature.
